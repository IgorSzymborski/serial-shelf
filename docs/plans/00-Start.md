> Projekt kończący obecny etap nauki Vanilla JavaScript.
> Autor: Igor / ISzymborski.
> Start: 21.09.2026.
> Technologie: HTML, CSS, JavaScript, TVmaze API, Git i GitHub.
> Repozytorium: serial-shelf.

## Jak korzystać z tego planu?

Piszesz aplikację samodzielnie. Plan określa zadania, wymagania i kierunek, ale nie zawiera gotowego kodu aplikacji.

Nie musisz czytać wszystkiego przed każdym wieczorem. Otwieraj dokument dotyczący aktualnego etapu.

## Pierwsze zadanie

- [ ] Utwórz katalog projektu i repozytorium serial-shelf.
- [ ] Dodaj pierwsze pliki.
- [ ] Zrób pierwszy commit i push.
- [ ] Obejrzyj odpowiedź API.
- [ ] Rozpisz sekcje HTML.
- [ ] Zbuduj formularz i jedną statyczną kartę.
- [ ] Sprawdź ją na telefonie i desktopie.
- [ ] Pokaż HTML/CSS lub zrzut ekranu do przeglądu.

Nie czekaj z GitHubem do ukończenia aplikacji. Historia jej powstawania jest częścią projektu.

## Organizacja dokumentów

Trzymaj wszystkie pliki tego planu w jednym katalogu, np. docs/plan/.

Dzięki temu odnośniki między nimi będą działały w VS Code oraz na GitHubie.

Główne README.md repozytorium opisze aplikację. Ten zestaw dokumentów jest Twoim planem pracy.

## Wizualizacja

Dokładne kolory, fonty i wymagania interfejsu znajdziesz w pliku 02.
